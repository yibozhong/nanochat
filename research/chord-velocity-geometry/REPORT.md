# 速度必须在球面的切平面上吗？

## 假设与实验设计

零初速的完整 Chord 在同一 1B 协议下已完成训练，最终 validation CE 为 3.207224。新实验检验移除速度切向约束后，模型是否使用径向分量，以及这是否改变 CE。[配对基线 aa44a2d7](../legacy-chord-1b/configs/aa44a2d7.json)

两边均用 vanilla 8×512、v₀=0、BF16、每 token 六系数、soft force τ=0.05、零输出投影、seed 42 和相同 FineWeb-Edu 数据顺序。每步 32,768 tokens，共 30,518 步。位置更新和两次方向分解的系数均相同。

| 速度写入 | 旧速度 u | 位移 d |
|---|---|---|
| 默认切向版 | P(h′, v) | P(h′, h′ − h) |
| 平行移动 + 切向投影 | P(h′, T(h→h′, v)) | P(h′, h′ − h) |
| 自由速度版 | v | h′ − h |

两版都沿 u 将 d 分解为平行和垂直分量，以 βu + γ∥d∥ + γ⊥d⊥ 写入速度。自由速度版在前瞻时用 h + μv 的实际 RMS，包含 h 与 v 的交叉项。默认版利用切向性简化该分母，BF16 舍入下两种归一化可能略有差异。

主判据为同 token 的 validation CE 曲线及 1B 终点 ΔCE（自由速度减切向）。验证时记录各子层输入速度的径向能量占总速度能量的比例，取最后一个验证 minibatch 每隔 32 个 token 的样本，零速度记为零。速度和峰值显存按 GPU 型号解释。GPU 预检另用同卡的切向六系数配方作短测速。

### 平行移动的配对实验

平行移动版与默认切向版均从静止开始。位置更新完成后，用 b = h + h′ 求 T(h→h′, v) = v − 2·mean(v·b)/max(mean(b²), 1e−12)·b（点乘在此表示逐元素乘法）。对同半径球面上的切向速度，这是沿短大圆弧的平行移动。终点切向投影修正 BF16 舍入误差；精确对跖点没有唯一短弧，b=0 时沿用旧实现保留旧速度再投影的约定。β 保留搬运后的速度，γ∥ 和 γ⊥ 以该速度为参考分解终点切向位移。两端均参与反向传播，计算复杂度为 O(d)。

本次以 aa44a2d7 为基线，主指标为同 token validation CE 及 1B 终点 ΔCE（平行移动减仅投影）。对照保留相同的切向约束，可单独测量搬运旧速度的贡献。短测比较同卡每步用时，并以已知旋转、独立 FP64 公式及其梯度验证写入。
