# Mean + variance + third central moment attention

User authorized implementation, GPU validation, and then one formal 10B run.
`--attention-kernel fla_triton --attention-statistic variance_third` computes

```
mu = A V
m2 = A (V^2)
m3 = A (V^3)
s  = max(m2 - mu^2, 0)
c3 = m3 - 3 mu m2 + 2 mu^3
output = Wo(mu) + Ws(s) + W3(c3)
```

Operations are per head/channel. There is no variance denominator, extra norm,
learnable alpha, or clipping of signed c3. Ws and W3 are separate bias-free D x D
projections, initialized at zero and optimized with existing Muon. Shared model
parameters/RNG match the variance baseline. D512/8 layers has 62,914,560 parameters
(+2,097,152 over variance), and retains the same Q/K/V, masking, and LM head.

One FLA-derived forward kernel reuses its on-chip probabilities for all three
products. The new kernels are generated by `../triton-moments/generate.py` into
`nanochat/third_moment_attention_kernels.py`. Existing baseline/two-stream kernels
remain byte-identical. Tile size64/stages1 bounds shared-memory/register pressure
from three simultaneous accumulators. No full A or transformed V tensors in HBM.

Q/K/V, transformed V dot operands, outputs and saved moments are BF16; online
softmax and matrix accumulators use standard FP32. Center with BF16 returned mu,
retaining unrounded m2/m3 accumulators on chip. The variance centering follows
the existing squared-mean BF16 convention; c3 polynomial arithmetic is FP32
before its final BF16 cast. Cubing and centralization can amplify rounding;
near-zero/first-token discrepancies are measured, not promised bitwise zero for
arbitrary BF16 values. No added high-precision attention path is used.

Analytic backward (gs includes the variance clamp mask; gt is the c3 adjoint):

```
gmu = go - 2 mu gs + (6 mu^2 - 3 m2) gt
g2  = gs - 3 mu gt
g3  = gt
dp  = gmu V^T + g2 (V^2)^T + g3 (V^3)^T
dV  = A^T gmu + 2 V (A^T g2) + 3 V^2 (A^T g3)
```

The softmax delta includes mu*gmu + m2*g2 + m3*g3. There are three backward
launches (preprocess/dQ/dKV). All branches differentiate through the same A.
